Règles de duel

Tout ce que vous avez besoin de savoir pour jouer.

1. Préparer le duel

  1. Choisis ton personnage dans la liste des PJ sauvegardés.
  2. Choisis le mode de jeu : duel à deux joueurs ou solo contre l’application.
  3. Choisis le livret de l’adversaire.
  4. Clique sur Commencer le duel.

2. Déroulement d’un tour

  1. Choisis la situation : Distance Accruepoour le 1er Round
  2. Choisis pour les suivants : Combat rapproché ou Distance Accrue.
  3. Applique l’éventuelle restriction reçue au tour précédent.
  4. Choisis ton action.
  5. L’application affiche le PG à annoncer.
  6. Entre le PG reçu de l’adversaire, ou laisse l’application le remplir en mode solo.
  7. Clique sur Résoudre.
  8. Tu verras l'image de l'adversaire s'afficher .

Couleurs des actions

Les couleurs servent surtout à repérer rapidement le type d’action, les restrictions possibles et certains bonus.

Rouge Attaques violentes ou dangereuses. Elles peuvent être interdites par certaines blessures ou restrictions.
Orange Attaques puissantes ou engagées. Elles profitent souvent de la différence de taille dans le calcul des dégâts.
Bleu Actions techniques, mouvements particuliers ou attaques liées au placement.
Jaune Actions rapides, coups simples ou options utilisables dans certaines situations contraintes.
Vert Actions prudentes, défensives ou de récupération selon les livrets.
Marron Actions de distance ou de situation spéciale, notamment liées à la Distance Accrue.

Certaines instructions indiquent par exemple : Pas de Bleu, Pas de Rouge ni d’Orange, ou Seulement Vert. Dans l’application, ces restrictions filtrent automatiquement la liste des actions disponibles.

3. Résultat et dégâts

  • La page de résultat indique si l’action provoque un SCORE.
  • Les dégâts sont calculés automatiquement avec le SCORE, le MOD, les bonus et la taille si nécessaire.
  • Si des dégâts sont indiqués, clique sur Appliquer les dégâts à l’adversaire.
  • L’instruction à lire à l’adversaire s’affiche pour le tour suivant.

4. Fin du combat

  • Si l’adversaire tombe sous 1 Point de Corps et que ton PJ a encore au moins 1 Point de Corps : combat gagné.
  • Si les deux combattants tombent sous 1 Point de Corps : match nul.
  • Si ton PJ tombe sous 1 Point de Corps et que l’adversaire reste debout : combat perdu.
  • Si ton PJ tombe à -5 Points de Corps ou moins : mort du PJ.

5. Expérience

  • En cas de victoire, le PJ gagne automatiquement une quantité d’expérience liée aux Points de Corps de départ de l’adversaire.
  • Les XP sont affichées sous la forme : XP disponibles / XP utilisées.
  • Quand le PJ a assez d’XP, l’application propose une évolution.

6. Évolution du personnage

  • Quand l’expérience disponible atteint le coût nécessaire, tu peux améliorer une action.
  • Une action améliorée gagne un bonus permanent.
  • Quand toutes les actions d’une même couleur ont progressé, le PJ gagne un bonus de Points de Corps de départ pour les prochains combats.

7. Sauvegarde des PJ

  • Les PJ sont sauvegardés automatiquement sur l’appareil utilisé.
  • Le bouton Exporter ce PJ crée une sauvegarde JSON du personnage choisi.
  • Le bouton Exporter tous crée une sauvegarde de tous les PJ.
  • Le bouton Importer PJ permet de restaurer une sauvegarde JSON.
