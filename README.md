# Mondes Perdus - Duels

Application personnelle et familiale pour jouer des duels inspirés du système Mondes Perdus.

## Objectif

Remplacer les livrets papier par un écran de téléphone :

- choix de sa fiche personnage ;
- choix du livret de l’adversaire ;
- affichage du PG à annoncer ;
- saisie du PG reçu ;
- affichage de la bonne page de résultat ;
- calcul automatique des dégâts ;
- sauvegarde locale des fiches.

## Personnages prévus

- Homme en cotte de mailles avec épée et bouclier
- Squelette avec cimeterre et bouclier

## Usage

Projet personnel, familial, non officiel et sans but commercial.
